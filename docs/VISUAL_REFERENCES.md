# Schoology visual references

The redesign was based on publicly available screenshots of Schoology, inspected before implementation. The official PowerSchool documentation (`uc.powerschool-docs.com`) and Schoology's public site were inaccessible through this environment's network policy. The accessible references below show the actual Schoology interface with a third-party extension installed; extension-specific widgets, advertising overlays, and themes were not copied into the game.

- [Schoology Plus: Quick Access screenshot](https://github.com/aopell/SchoologyPlus/blob/master/src/static/imgs/quick-access.png): uppercase Courses / Groups / Resources / Grades navigation; header action icons; recent activity / course dashboard tabs; right-hand Upcoming section, date dividers, assignment icons, and due times.
- [Schoology Plus: What-if Grades screenshot](https://github.com/aopell/SchoologyPlus/blob/master/src/static/imgs/what-if-grades.png): Grades / Attendance tabs, Current / Past controls, assignment rows, point totals, percentage cells, dotted row separators, and course-grade summary panel.
- [Schoology Plus: Themes comparison](https://github.com/aopell/SchoologyPlus/blob/master/src/static/imgs/themes.png): overall Schoology content proportions, compact typography, gray page background, blue links, header layout, and activity/sidebar separation. These images include custom themes, so their exact palette is not treated as a definitive stock-site reference.

The game's course grid, material list, grade table, and month calendar are original HTML/CSS recreations. All course thumbnails, crest, logo treatment, and icons are local SVG/CSS. No screenshots, third-party extension code, live student records, or remote assets are loaded by the game. Student names, assignments, school details, and grades are fictional.

This is a recognizable Schoology-inspired recreation, not a claim of pixel-identical reproduction across every Schoology version or school theme.
